Inside the explorer

How to use the explorer

  1. Open the explorer, pick a camera and lens, and edit their specifications. Sensor presets have fixed, representative dimensions. Select Custom to type width and height or drag their sliders. The closest format is an approximate comparison; green and red messages check dimension limits and lens coverage, not whether a sensor product exists.
  2. The Camera + lens switch starts enabled, showing optical results. Turn it off to inspect the camera sensor alone, then turn it on to restore the lens. Each comparison configuration keeps its own state.
  3. On desktop, use the Camera, Lens and Target scene settings tabs. The workbench keeps the diagram and key results together; Full screen expands it without the introduction. Expand the help and detailed metrics when you need them.
  4. Target distance sets the measurement plane in front of the camera. Object width sets an object's real width on that plane, used to estimate its size in pixels. The distance slider changes that plane; it does not move the image-preview camera.
  5. The Aperture view pairs the opening with an illustrative image. Changing the f-number updates brightness and background blur. Keep image brightness compensates exposure so you can compare blur; shutter speed and ISO are otherwise held fixed, with f/2.8 as the brightness reference.
  6. Select Compare to edit A and B independently and inspect any view side by side. Copy A → B starts a controlled comparison.
  7. Export results as JSON or CSV, or export supported 2D diagrams as SVG. Select Share to copy a URL containing both configurations and the active view.

Everything runs in your browser. No account or server is needed.

Optical assumptions

Field of view and target coverage use a rectilinear, infinity-focus pinhole model. Aperture does not change this nominal field of view. Depth of field uses a thin-lens model and the chosen circle of confusion. At close focus, finite conjugates and real focus breathing can change framing.

Coverage assumes a centred circular image circle and describes geometry, not measured vignetting or image quality. Pixel pitch is derived only when resolution represents the physical pixel array. Preview exposure and defocus are not simulated; iris blades are illustrative.
